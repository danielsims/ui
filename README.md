# ui

A collection of interface experiments developed by [@danielsims](https://x.com/danielsims)

## Components

| Component                                         | Description                                                                    | Source                                                                                                                |
| ------------------------------------------------- | ------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------- |
| [Browser](https://ui.danielsi.ms/browser)         | A browser component that displays iframe or video content                      | [browser/browser.tsx](https://github.com/danielsims/ui/blob/main/packages/ui/src/browser/browser.tsx)                 |
| [ChatInput](https://ui.danielsi.ms/input)         | A chat input for interacting with language models                              | [chat-input/chat-input.tsx](https://github.com/danielsims/ui/blob/main/packages/ui/src/chat-input/chat-input.tsx)     |
| [Image](https://ui.danielsi.ms/image)             | Displays image content generated by language models                            | [image/image.tsx](https://github.com/danielsims/ui/blob/main/packages/ui/src/image/image.tsx)                         |
| [Thread Rail](https://ui.danielsi.ms/thread-rail) | A rail for navigating long chat threads, with hover previews and click to jump | [thread-rail/thread-rail.tsx](https://github.com/danielsims/ui/blob/main/packages/ui/src/thread-rail/thread-rail.tsx) |
